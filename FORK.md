# Fork notes

Trimmed fork of [caelestia-dots/shell](https://github.com/caelestia-dots/shell) for Fedora Asahi (Apple Silicon)
on Hyprland, themed Catppuccin Mocha. Runs without the `caelestia` CLI. Remote `upstream` points at the
original repo; merge from it to update.

## Changes from upstream

- **Removed** (code and build deps): launcher calculator (`libqalculate`), audio visualiser bars and the
  media tab's visualiser ring (`libcava`), beat tracking for the bongo cat GIF (`aubio`), and the PipeWire
  audio capture they shared (`libpipewire`). Config: `background.visualiser`, `services.visualiserBars`,
  `general.mediaGifSpeedAdjustment`.
- **Colour schemes from files, no generation**: no wallpaper-based (dynamic) schemes or variants. Schemes are JSON
  files shaped like the state `scheme.json` (`{"name", "flavour", "mode", "colours": {role: hex}}`):
  - bundled: `assets/schemes/<name>/<flavour>.json`, generated by `scripts/generate-schemes.py` from each theme's
    official palette (not the CLI's Material-harmonized ones), adjusted only where needed to meet WCAG contrast: catppuccin, dracula, everforest, gruvbox, nord,
    oldworld, onedark, rosepine, solarized and tokyonight. caelestia (dark, light), everblush and shadotheme are
    copied unchanged from the CLI (`scripts/upstream-schemes`, GPL-3.0); darkgreen is left out. Where a theme has
    dark and light versions, the mode is part of the flavour (`gruvbox dark-hard`, `everforest light`);
  - user: `*.json` anywhere under `paths.schemeDir` (default `~/.config/caelestia/schemes`, env
    `CAELESTIA_SCHEMES_DIR`). A missing `name`/`flavour` defaults to the folder/file name
    (`nord/dark.json`), a missing colour to bundled Mocha, and a user scheme replaces a bundled one with the same
    name and flavour. A missing folder is fine (no schemes, no error) and is picked up when created.

  `services/Schemes.qml` lists them for the launcher's `>scheme` picker (upstream's `SchemeItem` and "Scheme" action
  are kept) and IPC `scheme list/get/set <name> <flavour>`. Picking one copies it to
  `~/.local/state/caelestia/scheme.json`, which `services/Colours.qml` watches as upstream does (Mocha until one
  is picked). Only the shell is themed; the CLI also themed other apps. Removed: the variant picker, light/dark
  toggle and actions, and `services.smartScheme`.
- **Wallpapers**: `services/Wallpapers.qml` stores the current wallpaper in
  `~/.local/state/caelestia/wallpaper/path.txt` itself, with no scheme generation. Added IPC
  `wallpaper random`; the launcher's Random and Settings actions use `qs -c caelestia ipc call`.
- **Recording**: `assets/record.sh` uses `wf-recorder` instead of gpu-screen-recorder. wf-recorder can't
  pause, so the pause button is removed.
- **Removed widgets** for dependencies that aren't installed (widgets only, their sections stay):
  - caelestia CLI: CLI version row (About), "Smart colour scheme" toggle (Services), "Dark theme" toggle
    and "Colours" button (Wallpaper & style), "Variants" fuzzy-search toggle (Launcher)
- **Brightness**: monitors without DDC (all external monitors on Asahi) are not controllable
  (`Brightness.Monitor.controllable`): no OSD brightness slider, no bar-scroll/IPC changes. Upstream falls
  back to brightnessctl for them, which changes the laptop panel instead.
- **Temperatures**: a reading of 0 (the services' value when there's no sensor) shows "N/A" on the performance
  cards and lock screen. Asahi exposes no CPU/GPU die temperature, and the CPU service only knows Intel/AMD labels.
- **Lyrics**: the dashboard media tab's lyrics panel and the "Lyrics backend" setting are removed (no more
  LRCLIB/NetEase lookups); the tab is narrower, with the player switcher moved under the playback controls
  (`modules/dashboard/media/PlayerSelector.qml`). The C++ `Lyrics` service and its config (`services.lyricsBackend`,
  `paths.lyricsDir`) are removed too; the services plugin no longer links Qt Network.
- **GIFs removed**: the bongo cat under the dashboard's media controls and the spinning GIF in the session menu,
  with their assets and config (`paths.mediaGif`, `paths.sessionGif`, `general.sessionGifSpeed`).

## Build

Only the C++ parts are built; the repo itself is the Quickshell config (`qs -c caelestia`).

```sh
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DENABLE_MODULES="extras;plugin" \
    -DCMAKE_INSTALL_PREFIX="$HOME/.local" -DCMAKE_INSTALL_LIBDIR=lib
cmake --build build
cmake --install build
```

Needs [m3shapes](https://github.com/soramanew/m3shapes) in the same prefix, and at runtime
`QML_IMPORT_PATH=~/.local/lib/qt6/qml` and `CAELESTIA_LIB_DIR=~/.local/lib/caelestia`.
